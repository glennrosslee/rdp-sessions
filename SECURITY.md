# Security

Use GitHub's **Security → Report a vulnerability** form to report a security issue privately. Include the app and Windows versions and the expected and observed behaviour. Use synthetic hostnames and settings. Remove credentials, real hostnames, usernames, local paths, and private screenshots before attaching anything.

RDP Sessions launches Windows Remote Desktop Connection. Report issues in that client or the Windows RDP protocol to the [Microsoft Security Response Center](https://msrc.microsoft.com/report/vulnerability).
